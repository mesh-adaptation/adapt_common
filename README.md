# `adapt_common`
## Common functionality of Mesh Adaptation packages for Firedrake
![GitHub top language](https://img.shields.io/github/languages/top/mesh-adaptation/adapt_common)
![GitHub repo size](https://img.shields.io/github/repo-size/mesh-adaptation/adapt_common)

This repository holds common functionality for the following Mesh Adaptation
packages for the
[Firedrake finite element library](https://firedrakeproject.org):
* [Animate](https://mesh-adaptation.github.io/animate/index.html)
* [Movement](https://mesh-adaptation.github.io/movement/index.html)
* [Goalie](https://mesh-adaptation.github.io/goalie/index.html)
* [UM2N](https://mesh-adaptation.github.io/um2n/index.html)

## Documentation

There are two sources of documentation:
* The [website](https://mesh-adaptation.github.io/), which includes long-form
  documentation, demos, and API documentation.
* The [wiki](https://github.com/mesh-adaptation/mesh-adaptation-docs/wiki),
  which includes recommendations on how to interact with the codebase and
  development practices to be followed.

## Installation

For installation instructions, we refer to the
